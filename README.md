# Blood Bank Inventory & Donor Matcher

## Project Overview
The **Blood Bank Inventory & Donor Matcher** is a Java-based project developed for LifeCare Blood Bank. It helps manage donor details, search for donors, maintain blood inventory, and filter donors based on their blood groups.

## Objectives
- Register and store blood donor details.
- Maintain and display blood inventory.
- Search and sort donor records.
- Filter donors by blood group.
- Save donor records to a file.
- Demonstrate Java concepts from CO1 to CO6.

## Course Outcomes Implemented
- **CO1:** Variables, data types, operators, and input/output.
- **CO2:** Conditional statements and loops.
- **CO3:** Methods, recursion, and arrays.
- **CO4:** Classes, objects, constructors, and encapsulation.
- **CO5:** String handling, searching, sorting, and file handling.
- **CO6:** Collections, lambda expressions, functional interfaces, and Streams.

## Project Files
- `BloodBankCO1.java` — Basic donor information and calculations.
- `BloodBankCO2.java` — Control flow and decision-making.
- `BloodBankCO3.java` — Arrays, methods, and recursion.
- `BloodBankCO4.java` — Classes, objects, and encapsulation.
- `BloodBankCO5.java` — String operations, searching, sorting, and file handling.
- `BloodBankCO6.java` — Collections, lambdas, predicates, and Streams.
- `BloodBankIntegrated.java` — Complete integrated project.

## Technologies Used
- Java
- Object-Oriented Programming
- Java Collections Framework
- File Handling
- Functional Programming concepts

## How to Run
1. Install the Java Development Kit (JDK).
2. Download or clone this repository.
3. Open a terminal in the folder containing `BloodBankIntegrated.java`.
4. Compile the program:

   `javac BloodBankIntegrated.java`

5. Run the program:

   `java BloodBankIntegrated`
